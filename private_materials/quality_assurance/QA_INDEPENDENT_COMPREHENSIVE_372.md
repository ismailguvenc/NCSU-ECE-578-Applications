## Pedagogical recommendations and release gates

1. **Differentiate modeling levels:** students should see that theoretical capacity, link-level toy experiments, and standards-accurate throughput differ. App explanations label simplified assumptions; add measured AERPAW data later only where source and calibration exist.
2. **Guided use of each lab:** in class, have students predict changes (e.g., fixed receive power vs constant SNR bandwidth, oversampled vs nominal PAPR, PF vs maximum-rate fairness), manipulate one variable, then interpret metrics.
3. **Standards specificity:** where a behavior differs between LTE Release 8, LTE-Advanced, 5G NR, and newer revisions, state the release and configuration before assigning questions for grades. The source deck includes historical slides and 2026 5G material.
4. **Question-bank security:** answers and explanations are purposely readable offline; do not use this page as a proctored exam. Retain original asterisk keys and provenance for instructor inspection; content can be used as ungraded practice.
5. **Before production:** faculty audit every keyed technical claim, test real local file launch in Chrome/Edge/Safari, check keyboard-only navigation and accessibility, and spot-check layout on mobile/projector screens. Validate calculations against known reference link budgets or SDR captures for research-quality demonstrations.
