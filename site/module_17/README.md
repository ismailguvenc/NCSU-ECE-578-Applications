# ECE 578 — Module 17 Course-Wide Quiz Laboratory

Launch `index.html` from the extracted full course package or open `Quiz_Standalone.html` for a one-file offline version.

## Questions
- 135 instructor-keyed legacy questions from Respondus M1–M15, reviewed/edited and annotated.
- 237 new questions, including expanded 5G NR material.
- The file named Respondus M16 is a consolidated duplicate of the legacy bank, not an additional Module 16 set.
- The complete data plus original text and source provenance are in `questions.json`.

## Functionality
Practice and test modes, module/source filters, 10/20/40/80/all session sizes, search, progress, immediate/delayed explanation, module-level score breakdown, missed question retake, TXT self-review export, 372-item Respondus-style key-marked export and CSV explanation table.

The app runs without server-side services. Client-side code is **not secure for proctored assessment**. `REVIEW_LOG.md` details the first-pass technical review and areas for additional checking.

## Open content
- `index.html` expects `../shared/style.css` and `questions.js` / `quiz.js` / `quiz.css`.
- `Quiz_Standalone.html` embeds all of those assets for independent offline use.

**Expanded edition (2026-11-15):** 372 items = 135 original revised Respondus questions + 237 new practice questions. See `study_questions.html` (all answers visibly marked and grouped by module), and `Respondus_Reviewed_Expanded.txt` for the asterisk-keyed export.
