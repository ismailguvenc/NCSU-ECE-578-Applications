Analytic planning tradeoff: update overhead versus paging overhead

Boundary-triggered TAU rate / UE ≈ (4/π) · v / (L √N)   [events/hour]
Paging messages / UE / hour ≈ λpage · N   [cell-deliveries/hour]
Weighted cost = U · (cTAU · TAUrate + cpage · λpage · N)
Critical distinction: This analytic planning curve assumes one registered TA and no periodic updates. The map separately demonstrates multi-TA lists, periodic TAU events, and wider paging reach. Real TA list allocation and paging retry algorithms are network specific. A larger TA can lower TAU frequency but increase paging fan-out. Source motivation: Module 2 Slide 15; 3GPP TS 23.401 §4.3.5.2 and §5.3.3.0. Tracking-area list and reachability reference.
